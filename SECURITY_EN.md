# Security

[简体中文](SECURITY.md)

Report reproducible plugin or bridge security defects privately to
`6jeffr3y@users.noreply.github.com` before public disclosure.

Include the Burp version, bridge configuration, MCP transport, exact request,
and a minimal reproduction. Do not include unrelated target credentials,
tokens, or captured production traffic.

For defects that may block Proxy traffic, modify messages unexpectedly, or
cross the intended local network boundary, include the timeout, unload, and
bind-address conditions in the report.
