BurpSuite MCP Bridge

This distribution contains prebuilt Burp extension artifacts, a Python MCP
adapter, client configuration examples, and operating documentation.

The supplied configuration binds local services to loopback. Review bind
addresses, firewall rules, authentication boundaries, and exported traffic
before adapting the package to another environment.
